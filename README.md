# VoucherKit — ระบบคูปอง / ส่วนลดออนไลน์

คูปองที่ลูกค้าเปิดบนมือถือ **ไม่ต้องปริ้นเป็นใบ** พร้อมทั้งหน้าตา ตรรกะการใช้สิทธิ์
และวิธีเอาไปต่อกับเว็บหรือแอปของบริษัท

ทำมาให้ **ต่อยอดได้เรื่อย ๆ** ไม่ใช่ของที่เสร็จแล้วจบ — เพิ่มชนิดคูปองใหม่
เปลี่ยนหน้าตาทั้งระบบ หรือย้ายไปเก็บข้อมูลบนเซิร์ฟเวอร์จริง ทำได้โดยไม่ต้องรื้อของเดิม

---

## เปิดดูเลยใน 30 วินาที

```bash
node tools/dev-server.mjs
```

แล้วเปิด <http://localhost:4173> — ไม่ต้องติดตั้งอะไรเพิ่มทั้งสิ้น (ใช้ Node เปล่า ๆ)

| หน้า | ทำอะไร |
|---|---|
| `/demo/index.html` | รวมหน้าตาทั้งหมด · สลับธีมได้สด ๆ |
| `/demo/wallet.html` | **กระเป๋าคูปองของลูกค้า** — คูปองที่ตัวเองมี |
| `/demo/voucher.html?c=รหัส` | **คูปองใบเดียว** — กดใช้สิทธิ์ได้จริง |
| `/demo/staff.html` | **หน้าร้าน** — พนักงานกรอกรหัส ตรวจ แล้วตัดสิทธิ์ |
| `/demo/admin.html` | **ออกคูปอง** — กรอกฟอร์มแล้วปั๊มทีละหลายร้อยใบ |

ตรวจว่าตรรกะทั้งหมดยังถูก:

```bash
node tools/selftest.mjs
```

## คูปอง 1 ใบทำงานยังไง

```
ออกคูปอง  →  ส่งให้ลูกค้า  →  ลูกค้าเปิดดู  →  ใช้ที่หน้าร้าน/ตอนจ่ายเงิน  →  ตัดสิทธิ์
 (แอดมิน)     (ลิงก์/QR)      (มือถือ)          (พนักงานตรวจ)              (ใช้ซ้ำไม่ได้)
```

ของสำคัญ 3 อย่างที่แยกออกจากกันตั้งแต่แรก — นี่คือเหตุผลที่ระบบนี้ต่อยอดง่าย

| ชั้น | อยู่ที่ | หน้าที่ | เปลี่ยนแล้วกระทบใคร |
|---|---|---|---|
| **ข้อมูล** | `src/core/schema.js` | คูปองมี field อะไรบ้าง | ทุกชั้น (แก้ที่นี่ก่อนเสมอ) |
| **ตรรกะ** | `src/core/rules.js` | ใช้ได้ไหม · ลดเท่าไหร่ | ไม่กระทบหน้าตา |
| **หน้าตา** | `src/tokens/` + `src/styles/` | สี ฟอนต์ รูปทรง | ไม่กระทบตรรกะเลย |

## ทำอะไรได้แล้วบ้าง

**ชนิดสิทธิ์** — ลด % · ลดเป็นบาท · ราคาพิเศษ · ของแถม · ส่งฟรี

**เงื่อนไข** — ยอดขั้นต่ำ · เพดานส่วนลด · เฉพาะบางสินค้า/หมวด · เฉพาะบางสาขา ·
เฉพาะบางช่องทาง (เว็บ/แอป/หน้าร้าน) · ใช้ร่วมกับส่วนลดอื่นได้หรือไม่

**กลุ่มเป้าหมาย** — ทุกคน · พาร์ทเนอร์ · ลูกค้าประจำ · ลูกค้าเก่า · ลูกค้าใหม่ · พนักงาน
หรือผูกกับลูกค้าคนเดียวเลยก็ได้

**โควตา** — จำกัดต่อคน · จำกัดจำนวนรวม · หรือปล่อยเป็นโค้ดสาธารณะ

**กันปัญหาที่เจอจริงในร้าน**
- รหัสมี **ตัวตรวจทาน** — พนักงานพิมพ์ผิด 1 ตัวระบบรู้ทันที ไม่ไปบอกว่า "ไม่พบคูปอง"
- ตัดตัวอักษรที่คนอ่านสลับกันออกจากรหัส (I · L · O · U) และซ่อมให้อัตโนมัติถ้าพิมพ์มา
- **รหัสยืนยันสด 4 หลัก** เปลี่ยนเองทุก 30 วินาที → ลูกค้าแคปหน้าจอส่งต่อให้เพื่อนไม่ได้
- **จองคูปองไว้ 5 นาที** ระหว่างกำลังจ่ายเงิน กันใช้ซ้ำจากสองเครื่องพร้อมกัน
- **QR สร้างในเครื่อง** ไม่ยิงรหัสของลูกค้าออกไปให้เว็บนอก และเปิดได้แม้เน็ตไม่ดี

## หน้าตา

ธีมมาให้ 3 แบบ สลับได้ด้วยการเปลี่ยนค่าเดียวบน `<html>`:

| ธีม | คาแรกเตอร์ | เหมาะกับ |
|---|---|---|
| **steel** | เทากราไฟต์ + ส้มอิฐ · แบน คม | ค่าเริ่มต้น · งานอุตสาหกรรม/ก่อสร้าง |
| **ink** | หมึกดำบนกระดาษกระดูก · เส้นผมบาง | บัตรกำนัลมูลค่าสูง · งานพรีเมียม |
| **voltage** | กรมท่า + เขียวมะนาวไฟฟ้า | ของแจกจำนวนจำกัด · แคมเปญอีเวนต์ |

```html
<html data-vk-skin="steel" data-vk-mode="dark">
```

แต่ละธีมมีทั้งโหมดมืดและสว่าง · เพิ่มธีมใหม่ = เขียนไฟล์ค่าสีไฟล์เดียว
รายละเอียดอยู่ที่ [ระบบดีไซน์](docs/03-ระบบดีไซน์.md)

**หน้าตาของใบมี 3 แบบ** — ใบเต็ม (`slab`) · แถวในรายการ (`strip`) · ชิปเล็กในตะกร้า (`mini`)

## เอาไปใช้ในงานอื่น

ทั้งชุดเป็น JavaScript มาตรฐาน **ไม่พึ่งไลบรารีอะไรเลยสักตัว** เอาไปวางในเว็บอะไรก็ได้

```html
<gift-voucher layout="slab"></gift-voucher>
<script type="module">
  import { createVoucher } from './src/index.js';
  document.querySelector('gift-voucher').voucher = createVoucher({
    code: 'SPE-7K4M-92XH', kind: 'percent', value: 15,
    title: 'ส่วนลดพาร์ทเนอร์',
  });
</script>
```

ใช้กับ React / Vue / เว็บที่ทำอยู่แล้วก็ได้ — เรียก `voucherCardHtml(voucher)` เอา HTML ไปวางเอง

วิธีต่อกับหลังบ้านจริง ดูที่ [เอาไปต่อกับเว็บหรือแอป](docs/04-เอาไปต่อกับเว็บหรือแอป.md)

## สิ่งที่ยัง **ไม่** ได้ทำ (พูดตรง ๆ)

ระบบนี้ทดสอบบน **คอมพิวเตอร์** เท่านั้น ยังไม่มีใครเปิดบนมือถือจริง
และยังเป็นต้นแบบที่เก็บข้อมูลไว้ในเบราว์เซอร์ ไม่ใช่ระบบที่พร้อมรับเงินจริง

3 อย่างที่ **ต้องทำก่อนเปิดใช้จริง**:

1. **ย้ายการตัดสินใจไปหลังบ้าน** — ตอนนี้หน้าเว็บเป็นคนตัดสินว่าคูปองใช้ได้ไหม
   ซึ่งแปลว่าใครแก้หน้าเว็บในเครื่องตัวเองก็โกงได้ (ดู [เอกสาร 05](docs/05-ความปลอดภัยและกับดัก.md))
2. **ทดสอบบนมือถือจริง** โดยเฉพาะ iPhone
3. **ลองสแกน QR ด้วยกล้องมือถือจริง** — ตัวสร้าง QR ตรวจแล้วว่าตรงมาตรฐาน
   แต่ยังไม่มีใครยกมือถือขึ้นมาส่อง

รายละเอียดเต็มอยู่ใน [06 แผนพัฒนาต่อ](docs/06-แผนพัฒนาต่อ.md)
