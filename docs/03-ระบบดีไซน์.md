# 03 · ระบบดีไซน์

หน้าตาทั้งหมดคุมด้วย **โทเคน** (ค่าที่ตั้งชื่อไว้) ไฟล์กฎหน้าตาห้ามเขียนค่าดิบเอง
แก้ที่โทเคนที่เดียว = เปลี่ยนทั้งระบบ และเวลามีอาการแปลก ๆ จะไล่หาต้นตอได้เร็ว

---

## 1. แนวคิดของใบคูปอง

คูปองทั่วโลกหน้าตาเหมือนกันหมด — **เส้นประ + วงกลมเจาะสองข้าง + กรรไกร**
ระบบนี้จงใจไม่ทำแบบนั้น

คอนเซปต์คือ **"ชิ้นส่วนโลหะที่ถูกกัดขึ้นรูป"**

```
        ┌──────────────────────────╱     ← มุมขวาบนถูกตัดเฉียง
        │▌ PARTNER                 │
        │▌                         │        ▌ = แถบสีเน้นเส้นเดียว
        │▌ ส่วนลด · พาร์ทเนอร์      │
        │▌  15%                    │     ← ตัวเลขใหญ่มาก ชิดกันแน่น
        │▌ ส่วนลดพาร์ทเนอร์ ไตรมาส 3 │
        ├──────────────────────────┤     ← รอยต่อ = เส้นตรงคม + สลับโทน
        │▌ SPE-7K4M-92XH   31 ธ.ค. │
        ╲──────────────────────────┘     ← มุมซ้ายล่างถูกตัดเฉียง
```

องค์ประกอบที่ทำให้จำได้:

| ส่วน | ทำไม |
|---|---|
| **มุมตัดเฉียง 2 มุมตรงข้าม** | เงาของใบเป็นรูปเฉพาะ จำได้แม้มองไกล ๆ ไม่ใช่สี่เหลี่ยมโหล ๆ |
| **แถบสีเน้นเส้นเดียวชิดขอบซ้าย** | ความกล้ามาจากเส้นเดียว ไม่ใช่ใส่สีเยอะ ๆ |
| **ตัวเลขมูลค่าใหญ่มาก** | สิ่งที่ลูกค้าอยากรู้คือ "ได้อะไร" ต้องเห็นก่อนอย่างอื่น |
| **รอยต่อเป็นเส้นตรง + สลับโทน** | แบ่งใบเป็นสองท่อนเพื่อ "ฉีก" ตอนใช้สิทธิ์ โดยไม่ต้องพึ่งเส้นประ |
| **รหัสเป็นตัวพิมพ์กว้างเท่ากัน** | อ่านทีละตัวได้ชัด ไม่สับสนตอนพนักงานพิมพ์ตาม |

**จังหวะตอนใช้สิทธิ์** — กดค้าง 1 วินาที → ใบฉีกออกเป็นสองท่อนพร้อมเอียงเล็กน้อย
→ ขึ้นรหัสยืนยันสด นี่คือจุดที่ผู้ใช้จะจำระบบนี้ได้

## 2. โทเคน 3 กลุ่ม

### กลุ่ม ก · ผูกกับหน่วยฐาน `--vk-u` — `src/tokens/tokens.css`

ทุกระยะและขนาดตัวอักษรเป็น **จำนวนเท่าของ `--vk-u`** ตัวเดียว
ปรับตัวนี้ตัวเดียว ทั้งใบโตหรือเล็กลงโดยสัดส่วนไม่เพี้ยน

```css
--vk-u: 1rem;                        /* หน่วยฐาน = 16px */
--vk-space-4: calc(var(--vk-u) * 1); /* 16px */
--vk-text-value: calc(var(--vk-u) * 3.75); /* 60px */
```

บนตัวการ์ด `--vk-u` ยืดตามความกว้างของช่องที่ไปวางอยู่:

```css
.vk-card { --vk-u: clamp(0.8rem, 4.44cqw, 1.22rem); }
```

> ⚠️ **กับดักที่เคยพลาดมาแล้ว 2 ข้อ — อ่านก่อนแก้ไฟล์นี้**
>
> **1. `--vk-u` ต้องเป็น "ความยาว" ห้ามเป็นตัวเลขเปล่า**
> เคยเขียนเป็น `clamp(0.82, calc(100cqw / 360), 1.28)` ซึ่งผสมตัวเลขกับความยาว
> → ค่าเสียทั้งก้อน **แต่ไม่มี error สักตัว** padding กับ font-size แค่ตกกลับไปใช้
> ค่าเริ่มต้นของเบราว์เซอร์ ผลคือการ์ดแบนหมดทั้งใบ ตัวเลขส่วนลดกลายเป็น 15px
> เท่าตัวหนังสือธรรมดา
>
> **2. ตัวแปรที่ข้างในมี `var()` ตัวอื่น จะถูกแทนค่าตั้งแต่ตอนประกาศ**
> ไม่ใช่ไปคำนวณใหม่ที่ลูก ฉะนั้นบล็อกโทเคนกลุ่ม ก ต้องประกาศซ้ำทุกจุดที่ตั้ง
> `--vk-u` ใหม่ ตอนนี้มี 2 จุดคือ `:root` กับ `.vk-card`
> เพิ่มจุดใหม่ = เติมชื่อเข้าไปใน selector นั้น **ที่เดียว**

### กลุ่ม ข · ไม่ผูกกับสเกล — `src/tokens/tokens.css`

น้ำหนักตัวอักษร · ระยะตัวอักษร · ความสูงบรรทัด · จังหวะแอนิเมชัน · ชั้นซ้อน (z-index) ·
จุดหักหน้าจอ · ระยะปลอดภัยขอบจอมือถือ

> ⚠️ **ภาษาไทยกับ `line-height` และ `letter-spacing`**
> ไทยมีสระบน/ล่างและวรรณยุกต์ซ้อนกันได้ถึง 2 ชั้น ตั้ง `line-height` ต่ำกว่า ~1.1
> = วรรณยุกต์ชนบรรทัดบน จึงแยกเป็น 2 ค่า:
> `--vk-leading-tight: 0.9` ใช้กับ **ตัวเลขเท่านั้น** · `--vk-leading-display: 1.16` สำหรับพาดหัวไทย
>
> `letter-spacing` ก็เหมือนกัน ถ่างมากรูปคำไทยจะแตกเป็นตัว ๆ อ่านยาก
> `--vk-tracking-label: 0.09em` ใช้กับคำไทย · `--vk-tracking-widest: 0.18em`
> ใช้กับ**ตัวพิมพ์ใหญ่อังกฤษเท่านั้น**

## 3. สัญญาของ skin

ธีมใหม่ **ต้องประกาศครบทุกตัว** ในรายการนี้ ไม่งั้นสลับธีมแล้วมีจุดหลุด

| กลุ่ม | โทเคน |
|---|---|
| ฟอนต์ | `--vk-font-sans` `--vk-font-mono` `--vk-font-value` |
| พื้นผิว | `--vk-texture-card` `--vk-texture-strength` |
| พื้นหลัง | `--vk-bg-page` `--vk-bg-surface` `--vk-bg-card` `--vk-bg-card-2` `--vk-bg-inset` `--vk-bg-hover` |
| ตัวหนังสือ | `--vk-ink` `--vk-ink-muted` `--vk-ink-faint` `--vk-ink-on-accent` |
| เส้น | `--vk-line` `--vk-line-strong` |
| สีเน้น | `--vk-accent` `--vk-accent-soft` `--vk-accent-ink` |
| สีสถานะ | `--vk-ok` `--vk-ok-soft` `--vk-warn` `--vk-warn-soft` `--vk-dead` `--vk-dead-soft` |
| เงา | `--vk-shadow-card` `--vk-shadow-sheet` `--vk-sheen` |
| QR | `--vk-qr-dark` `--vk-qr-light` |

ประกาศ 3 ชั้น: ตัวธีม (ฟอนต์/พื้นผิว) → โหมดมืด → โหมดสว่าง

```css
[data-vk-skin='mine'] { --vk-font-sans: …; }
[data-vk-skin='mine'][data-vk-mode='dark']  { --vk-bg-page: …; }
[data-vk-skin='mine'][data-vk-mode='light'] { --vk-bg-page: …; }
```

**วิธีเพิ่มธีมใหม่**
1. ก๊อป `skin-steel.css` เป็น `skin-<ชื่อ>.css` แล้วแก้ค่าสี
2. เติมชื่อใน `SKINS` ที่ `src/core/schema.js`
3. `<link>` ไฟล์ใหม่ในหน้าที่ใช้

ไม่ต้องแตะโค้ดสักบรรทัด · หน้าแอดมินจะขึ้นตัวเลือกใหม่ให้เอง

## 4. สามธีมที่มีให้

| ธีม | คาแรกเตอร์ | เหมาะกับ |
|---|---|---|
| **steel** | เทากราไฟต์นิวทรัล + ส้มอิฐหนึ่งสี · แบน คมชัด ไม่มีไล่เฉดฟุ้ง | ค่าเริ่มต้น · งานอุตสาหกรรม/ก่อสร้าง |
| **ink** | ดำหมึกบนกระดาษกระดูก · เส้นผมบาง · แดงหมึกจุดเดียว | บัตรกำนัลมูลค่าสูง · งานพรีเมียม |
| **voltage** | กรมท่าเกือบดำ + เขียวมะนาวไฟฟ้า · ตัวเลขเป็นแบบพิมพ์ดีด | ของแจกจำนวนจำกัด · แคมเปญอีเวนต์ |

ทุกธีมมีทั้งโหมดมืดและสว่าง

โหมดมืดใช้ระดับ **"มืดแบบสบายตา"** ไม่ใช่ดำสนิท (พื้น `#27282b` การ์ด `#31333 7`)
ดำสนิทกับตัวหนังสือขาวจัดทำให้ตาล้าเวลาอ่านนาน ๆ บนมือถือ

## 5. รูปแบบใบ 3 แบบ

| แบบ | ใช้ตอน | ลักษณะ |
|---|---|---|
| `slab` | เปิดคูปองใบเดียว · หน้าที่ส่งให้ลูกค้า | ใบเต็ม มีทุกอย่าง สูงประมาณ 300px |
| `strip` | กระเป๋าคูปองที่มีหลายใบ | แถวแนวนอน อ่านเร็ว เห็นได้ 6-8 ใบต่อจอ |
| `mini` | ตะกร้าสินค้า · หน้าสรุปคำสั่งซื้อ | ชิปเล็ก แสดงแค่มูลค่ากับรหัส |

เลือกได้ทั้งตอนวาดและตอนเก็บข้อมูล:

```js
voucherCardHtml(v, { layout: 'strip' })     // สั่งตอนวาด
v.design.layout = 'strip'                   // หรือเก็บติดกับใบ
```

## 6. โครง HTML ของใบ

```html
<div class="vk-voucher" data-layout="slab">      ← กล่องวัดขนาด (ห้ามตัดทิ้ง)
  <article class="vk-card" data-status="active" data-kind="percent" data-code="…">
    <div class="vk-card__main">   …ครึ่งบน…   </div>
    <div class="vk-card__stub">   …ครึ่งล่าง… </div>
  </article>
</div>
```

**ทำไมต้องมี `.vk-voucher` ครอบอีกชั้น** — ใบคูปองต้องรู้ว่าช่องที่ตัวเองไปวางอยู่
กว้างเท่าไหร่ เพื่อย่อ-ขยายให้พอดี แต่หน่วยวัดของ CSS ที่ตอบเรื่องนี้ (`cqw`)
ใช้วัดตัวเองไม่ได้ ต้องวัดจากกล่องแม่

> ⚠️ กล่องที่ตั้ง `container-type: inline-size` จะ **วัดความกว้างจากเนื้อหาตัวเองไม่ได้**
> ใส่ `width: fit-content` เข้าไปมันจะยุบเป็นศูนย์ (เคยทำให้ชิปเล็กซ้อนทับกันจนอ่านไม่ออก)
> ชิปแบบ `mini` จึงปิดโหมดวัดขนาดทิ้งไปเลย

**สถานะบอกผ่าน `data-status`** ไม่ใช่ class — เขียน CSS ทับได้ง่าย และอ่านจาก JS ได้ตรง ๆ

## 7. ปรับหน้าตาโดยไม่แตะไฟล์ระบบ

**เปลี่ยนสีเน้นเฉพาะบางใบ**

```js
v.design.accent = '#1e88e5';
```

**ปรับขนาดทั้งใบ**

```css
.my-page .vk-card { --vk-u: 1.15rem; }   /* ใหญ่ขึ้น 15% ทั้งใบ */
```

**เขียนทับหน้าตาบางส่วน** — ระบบไม่ใช้ Shadow DOM โดยตั้งใจ เขียน CSS ทับได้ตรง ๆ

```css
.my-page .vk-card__num { font-family: 'ฟอนต์ของบริษัท'; }
```

## 8. เข้าถึงได้ · Accessibility

- ทุกใบที่กดได้มีปุ่มจริงซ้อนอยู่ (`.vk-card__hit`) → คีย์บอร์ดกับโปรแกรมอ่านหน้าจอใช้ได้
- ปุ่มกดค้างรองรับ Enter/Space ไม่ใช่แค่แตะจอ
- ปุ่มสูงอย่างน้อย 48px ให้นิ้วโป้งกดสะดวก
- `prefers-reduced-motion` — ผู้ใช้ที่ปิดแอนิเมชันในเครื่อง จะได้ระยะเวลาเป็น 0 ทุกตัว
- เส้นโฟกัสสำหรับคนใช้คีย์บอร์ดไม่ถูกลบทิ้ง

## 9. ฟอนต์

เก็บไว้ในโปรเจกต์เอง (`assets/fonts/`) **ไม่ดึงจากอินเทอร์เน็ตตอนใช้งาน**

เหตุผล: การ "สั่งใช้ฟอนต์" ไม่เท่ากับ "ฟอนต์ถูกโหลด" ถ้าดึงจากเน็ตแล้วโหลดไม่ได้
หน้าเว็บจะไม่ error เลย แค่เปลี่ยนไปใช้ฟอนต์อื่นเงียบ ๆ — ลูกค้าเปิดคูปองตอนเน็ตไม่ดี
= หน้าตาเพี้ยนทันทีโดยไม่มีใครรู้

- **Anuphan** — ตัวหลัก ไทย+อังกฤษ ทรงเรขาคณิต สะอาด สมัยใหม่ (4 น้ำหนัก)
- **IBM Plex Mono** — ตัวความกว้างเท่ากัน ใช้กับรหัสคูปอง

รวม 240 KB · แยกไฟล์ไทย/อังกฤษด้วย `unicode-range` เบราว์เซอร์โหลดเฉพาะที่ใช้จริง
