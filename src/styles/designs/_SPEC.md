## 3. ฟอนต์ — มีแค่ 2 ตระกูล เจ้าของงานเลือกเอง ห้ามใช้ตัวอื่น

| ตระกูล | น้ำหนัก | ใช้กับ |
|---|---|---|
| `Google Sans` | 400 500 700 | **ตัวอังกฤษและตัวเลขทั้งหมด** |
| `Noto Sans Thai` | 400 500 600 700 | **ตัวอักษรไทยทั้งหมด** |
| `IBM Plex Mono` | 400 500 | เฉพาะ **รหัสคูปอง** (ต้องอ่านทีละตัว) |

**เขียนสแต็กเดียวจบ — ไม่ต้องแยก element:**

```css
font-family: 'Google Sans', 'Noto Sans Thai', sans-serif;
```

เบราว์เซอร์เลือกให้ทีละตัวอักษรเอง เจอ A-Z 0-9 ใช้ Google Sans · เจอ ก-ฮ ใช้ Noto Sans Thai
ประโยคที่ปนไทย-อังกฤษได้ฟอนต์ถูกทั้งประโยคโดยไม่ต้องทำอะไรเพิ่ม

⛔ **ห้ามใช้** Anuphan · Trirong · Bai Jamjuree · Archivo — ถูกถอดออกจากโปรเจกต์แล้ว
⛔ **ห้ามใช้ `font-family: serif`** ระบบไม่มีตัวมีเชิงแล้ว จะได้ฟอนต์ของ OS ซึ่งคุมไม่ได้

### แล้วจะทำให้ "ดูหรู" ยังไงถ้าไม่มีตัวมีเชิง

ความหรูมาจาก **การจัดวาง ไม่ใช่ชนิดฟอนต์** — ใช้ของพวกนี้แทน:
- ที่ว่างเยอะกว่าที่คิด 2 เท่า
- น้ำหนักบาง (400) ตัวใหญ่ ๆ ตัดกับตัวเล็กหนา (700) ตัวจิ๋ว
- ถ่างตัวอักษร**อังกฤษพิมพ์ใหญ่**ให้กว้าง (0.18em ขึ้นไป) เป็นป้ายกำกับ
- เส้นผมบาง 1px ที่วางถูกที่
- ตัวเลขใหญ่มาก น้ำหนัก 400 ไม่ใช่ 700 (บางแล้วใหญ่ = แพง · หนาแล้วใหญ่ = ตะโกน)

⚠️ **ตัวหนังสือไทยตั้ง `line-height` ต่ำกว่า 1.1 ไม่ได้** วรรณยุกต์จะชนบรรทัดบน
ตัวเลขล้วนใช้ 0.85–0.95 ได้ · `letter-spacing` กับคำไทยอย่าเกิน 0.1em
(Noto Sans Thai มีหางวรรณยุกต์ยาวกว่า Anuphan ต้องเผื่อที่มากกว่าเดิม)

## 4. โครง HTML ที่ต้องจัดสไตล์ (แก้ไม่ได้ ต้องรับมือให้ครบ)

```html
<div class="vk-voucher" data-design="ชื่อคุณ" data-shape="ticket|compact">
  <article class="vk-card" data-status="active" data-kind="percent" data-code="…">

    <figure class="vk-card__art"><img …ภาพสินค้า…></figure>

    <div class="vk-card__main">
      <header class="vk-card__head">
        <span class="vk-card__logo"><img …โลโก้ดำ…></span>
        <span class="vk-card__brandname">SP EMPIRE</span>
        <span class="vk-card__pill" data-tone="ok">ใช้ได้</span>
      </header>

      <div class="vk-card__hero">
        <p class="vk-card__kicker">ส่วนลด · พาร์ทเนอร์</p>
        <p class="vk-card__value">
          <span class="vk-card__lead">฿</span>       <!-- มีเฉพาะบางชนิด -->
          <span class="vk-card__num">15</span>        <!-- อาจมี data-text="true" -->
          <span class="vk-card__unit">%</span>        <!-- มีเฉพาะบางชนิด -->
        </p>
        <h3 class="vk-card__title">ส่วนลดพาร์ทเนอร์ ไตรมาส 3</h3>
        <p class="vk-card__cond">เมื่อซื้อครบ ฿10,000 · ลดสูงสุด ฿2,000</p>
        <p class="vk-card__note">ขอบคุณที่ร่วมงานกับเรามาตลอด 3 ปี</p>
      </div>

      <span class="vk-card__badge">PARTNER</span>     <!-- มีบ้างไม่มีบ้าง -->
    </div>

    <aside class="vk-card__stub">
      <div class="vk-card__qr"><svg …></svg></div>
      <div class="vk-card__stub-body">
        <span class="vk-card__label">รหัสคูปอง</span>
        <span class="vk-card__code">SPE-7K4M-92XH</span>
        <span class="vk-card__label">ใช้ได้ถึง</span>
        <span class="vk-card__date">31 ธ.ค. 69</span>
      </div>
      <span class="vk-card__serial">SPE 7K4M 92XH</span>   <!-- ซ่อนอยู่ เปิดใช้ได้ -->
    </aside>

  </article>
</div>
```

**ทุก selector ต้องขึ้นต้นด้วย `[data-design='ชื่อคุณ']`** เพื่อไม่ให้ไปกวนดีไซน์อื่น

```css
[data-design='seal'] .vk-card { … }
[data-design='seal'][data-shape='ticket'] .vk-card { … }
```

**QR เป็น SVG ที่ใช้ `fill: currentColor`** → คุมสีด้วย `color` ที่ `.vk-card__qr`

## 5. สองทรงที่ต้องทำให้ครบทั้งคู่

| ทรง | กว้าง | โครงกริดจาก base | ใช้ตอนไหน |
|---|---|---|---|
| `ticket` | สูงสุด 720px | `1fr auto` (เนื้อหา / ก้านขวา) | ส่ง LINE · อีเมล · จอคอม · พิมพ์ |
| `compact` | สูงสุด 380px | `1fr` (เรียงลงล่าง) | มือถือ · ในกระเป๋าคูปอง |

- ทรง `ticket` ควรอยู่ราว **2.4–2.8 : 1** (กว้าง : สูง)
- ทรง `compact` ควรอยู่ราว **0.9–1.25 : 1** (เกือบจัตุรัส ถึงสูงกว่ากว้างนิดหน่อย)
- **ต้องเป็นสไตล์เดียวกันชัดเจน** มองปุ๊บรู้ว่าคู่กัน ไม่ใช่คนละดีไซน์
- ขนาดทุกอย่างผูกกับ `var(--vk-u)` (base ตั้งให้แล้วต่อทรง) → ย่อ-ขยายไม่เพี้ยน
  เขียน `calc(var(--vk-u) * 1.5)` แทนการใส่ px ตรง ๆ

## 6. รสนิยมของเจ้าของงาน — อ่านให้ดี

✅ **เอา** — กล้า มีลายเซ็นจำได้ · ที่ว่างเยอะ · คอนทราสต์สูง · ตัวเลขเป็นพระเอก
✅ ดีเทลที่ตั้งใจ เช่น รอยปรุฉีก เส้นผมบาง มุมตัด แถบสีเดียว

❌ **ห้ามเด็ดขาด** — ของที่เว็บทั่วไปทำกัน:
- เส้นประรอบใบ + วงกลมเจาะสองข้าง + ไอคอนกรรไกร (คูปองโหล)
- ไล่เฉดม่วง-ฟ้า หรือไล่เฉดฟุ้ง ๆ ทุกชนิด
- เงาฟุ้งใหญ่ ๆ · มุมโค้งมนมากทุกมุม
- ริบบิ้น/ดาว/ประกายแวววาว/emoji
- จัดกลางทุกอย่างจนไม่มีจังหวะ

🎯 **เกณฑ์ตัดสินตัวเอง 2 ข้อก่อนส่งงาน**
1. ถ้าลบโลโก้ออก ยังบอกได้ไหมว่านี่คือแบรนด์งานเหล็กพรีเมียม
2. นี่คือทางที่คนทั่วไปจะทำไหม — ถ้าใช่ **ทิ้ง แล้วดันต่อ**

## 7. ต้องรับมือให้ครบ (ไม่งั้นพังตอนใช้จริง)

- `data-status="redeemed|expired|void"` — base ทำให้เป็นสีเทาจางให้แล้ว จะเขียนทับก็ได้
- `.vk-card__num[data-text="true"]` — ค่าเป็นคำ เช่น **"ส่งฟรี"** ไม่ใช่ตัวเลข → ต้องย่อขนาดลง ไม่งั้นล้นใบ
- `.vk-card__lead` (฿) และ `.vk-card__unit` (%) — **บางใบไม่มี** ต้องไม่พังเมื่อหายไป
- `.vk-card__badge` และ `.vk-card__note` — บางใบไม่มี
- หัวข้อยาว 1–2 บรรทัด · **ต้องไม่ล้นออกนอกใบ**
- ทรง `compact` ต้องอ่านได้บนจอกว้าง 320px

## 8. วิธีตรวจงานตัวเอง (บังคับ ห้ามข้าม)

เซิร์ฟเวอร์รันอยู่แล้วที่พอร์ต 4173 — แคปหน้าจอออกมาดูด้วยตาจริง

```bash
node tools/shot.mjs "http://localhost:4173/demo/design-preview.html?d=ชื่อคุณ" out.png 900 1500
```

แล้ว **Read ไฟล์ PNG นั้นเพื่อดูจริง ๆ** — ห้ามเดาว่าออกมาสวย

ตรวจให้ครบทุกแบบด้วยการเปลี่ยน `&v=` :
`?d=ชื่อคุณ&v=percent` · `&v=amount` · `&v=fixed` · `&v=ship` (คำ ไม่ใช่ตัวเลข) · `&v=used` (ใบใช้แล้ว)

วนแก้จนกว่าจะพอใจจริง ๆ อย่างน้อย **3 รอบ** — รอบแรกไม่มีทางดี

⚠️ **"ไม่มี error" ไม่เท่ากับ "สวย"** — เลย์เอาต์พังไม่ทำให้เกิด error
